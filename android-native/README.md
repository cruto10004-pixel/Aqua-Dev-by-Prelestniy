# Aqua Native Android

Новый клиент Kotlin + Jetpack Compose, без WebView. Старый `android-app/` оставлен как историческая Capacitor-оболочка; workflow собирает только `android-native/`.

## Запуск и сборка

JDK 17, Android SDK 35, Gradle 8.9 (wrapper с SHA-256).

```sh
cd android-native
./gradlew lintDebug testDebugUnitTest assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Приложение автоматически подключается к `https://aqua-dev-by-prelestniy.up.railway.app` — вводить сервер не нужно. Войдите своим логином и паролем. ## GitHub Actions

Workflow `.github/workflows/android.yml`: push в main, PR с изменениями Android, ручной запуск и теги `v*`. Debug APK скачивается из Actions → завершённый запуск → Artifacts → `Aqua-debug-apk`. После слияния workflow доступен в main автоматически. APK для разработки подписан debug-ключом и не предназначен для Google Play.

Для подписанного релиза добавьте Repository Secrets:

- `AQUA_KEYSTORE_BASE64`: содержимое вашего keystore в base64.
- `AQUA_STORE_PASSWORD`: пароль хранилища.
- `AQUA_KEY_ALIAS`: alias ключа.
- `AQUA_KEY_PASSWORD`: пароль ключа.

Храните оригинальный ключ отдельно и резервируйте его: он нужен для обновления установленных release-сборок. Не коммитьте keystore. При теге `v*` workflow декодирует его во временную директорию runner, собирает release, удаляет ключ и публикует APK в GitHub Release. Без Secrets теговая сборка завершится ошибкой; debug Artifact успеет сохраниться.

## Реализовано в исходниках

Вход; регистрация через номер и код Telegram; восстановление; сессия; список чатов; REST-история с пагинацией; отправка текста и файлов; WebSocket-обновления и переподключение; реакции; изменение своих сообщений; удаление у себя; закрепление; просмотр изображений; поиск пользователей и добавление контактов; личные чаты; профиль; изменение пароля и скрытие активности; системный Back; IME insets; Splash и Aqua-иконка.

## Границы текущей версии

Это первый нативный клиент, ещё не полный перенос всех функций веба. Не перенесены запись голосовых, редакторы фото/видео, воспроизведение видео/файлов внутри приложения, библиотека стикеров, управление каналами/группами, пересылка, настройки уведомлений и полноценные профили собеседников. Нет фонового push-сервиса. Нативная morph-анимация ещё не прошла проверку на устройстве. Не заявляется проверенная функциональность только на основании компиляции.

В sandbox проверена сборка APK; запуск, клавиатура, восстановление после сворачивания и API-сценарии именно на Android-устройстве требуют отдельной проверки. `/dev/kvm` отсутствует. Веб и сервер тестируются отдельно на синтетической локальной базе.
