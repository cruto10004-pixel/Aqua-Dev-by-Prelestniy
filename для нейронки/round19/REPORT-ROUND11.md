# Aqua round 11 — отчёт

## Реализовано

Работа продолжена с локального round10. Сохранены его структура, функции, типографика Onest, страницы, реакции, общие элементы перехода чата и история. Новый интерфейс с нуля не создавался.

- Нижний dock: иконки без подписей, прозрачные слои с blur, отдельный круглый поиск, стеклянный индикатор.
- Реальное перемещение индикатора Pointer Events, подсветка ближайшей вкладки до отпускания, фиксация через существующую навигацию, отмена и подавление повторного click. Touch использует Pointer Events без параллельных Touch-обработчиков.
- Морфинг поиска согласован с новой круглой кнопкой. Добавлены debounce локального фильтра и aria-busy; сохранены пустые результаты, фокус, Escape и VisualViewport.
- Канал: отдельные шаги имени и описания, добавлен шаг локальных уведомлений, сохранение выбора и возврат между шестью формами, создание и переход в канал.
- Увеличен вторичный статус шапки. Убрана фиктивная смена статуса нового сообщения на «Отправлено» по таймеру; добавлен SVG локального сохранения.
- Исправлен сборщик standalone: теперь включает CSS из link как с закрывающим слешем, так и без него (ранее пропускался pages.css).

## Решение по Anime.js

Изучены [официальный репозиторий](https://github.com/juliangarnier/anime), package.json, MIT-лицензия и [API animate](https://animejs.com/documentation/animation/). Просмотренная версия master: 4.5.0, runtime dependencies в manifest нет. Загруженный UMD: 118043 байта, gzip 40685 байт (размер зависит от версии). API подходит для свойств CSS, SVG, объектов и временных последовательностей; есть WAAPI-вариант. Совместимость конкретной библиотеки в Safari здесь не тестировалась.

Библиотека не добавлена: round10 уже имеет единый исполнитель WAAPI с прерыванием, отменой, reduced motion и управляемой сценой чата. Дублирование или полная замена этого слоя не требуется для выполненных изменений. Анимации вкладок остаются горизонтальными.
