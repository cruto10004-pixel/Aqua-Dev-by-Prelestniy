# Aqua — HTML-прототип round19

Актуальная версия — **round19**, продолжение round18. Это самостоятельный клиентский прототип Aqua. Основной репозиторий не изменён; публикации и серверной интеграции нет.

## Открытие

- Самый простой вариант: откройте `aqua-standalone.html` в современном браузере. CSS, JavaScript, шрифты, изображения и демовидео уже встроены. Интернет не нужен.
- Для разработки распакуйте **все файлы ZIP в отдельную папку**, выполните в ней `python3 serve.py` и откройте `http://127.0.0.1:4175`. Основной исходный HTML — `index.html`.
- Для другого порта: `python3 serve.py --port 8080`. Сервер использует только стандартную библиотеку Python 3 и поддерживает HTTP Range для перемотки видео. Обычный `python -m http.server` не рекомендуется для проверки видеоплеера.
- После изменения исходников: `python3 build-standalone.py`. Не редактируйте сгенерированный автономный HTML вручную.

## Что попробовать

1. Откройте вкладку профиля. Нажмите аватар: круг станет квадратом. Повторное нажатие открывает просмотр на весь экран; стрелка слева или Back возвращает раскрытый аватар. Прокрутка вниз сворачивает его.
2. Кнопка «Фотография» принимает PNG/JPEG/WebP до 3 МБ. Фото уменьшается до 960 px по большей стороне и сохраняется только в браузере.
3. Создайте канал через «+» в чатах; прикрепите его в настройках аккаунта. Карточка профиля открывает страницу канала. Это локальная демонстрация.
4. «ID пользователя» показывает отдельно серверный ID (пока не назначен) и копируемый локальный ID. Смена юзернейма его не меняет.
5. Настройки → Конфиденциальность → любой параметр доступа. Собственная панель Aqua предлагает «Все», «Мои контакты», «Никто»; исключения остаются на странице параметра.
6. В переписке откройте фото или видео. Фото перелистываются кнопками/стрелками клавиатуры/горизонтальным жестом, когда в переписке несколько изображений. Видео имеет собственные play/pause, таймлайн, громкость, mute, меню и fullscreen.

## Ограничения

- Данные прототипа не отправляются на сервер. Профиль и предпочтения сохраняются в `localStorage` (`aqua-preferences`); обычные сообщения и большинство созданных сущностей живут в памяти вкладки.
- Для прикреплённого канала сохраняется снимок его информации, но не публикации. Смена браузера/очистка хранилища не сохраняет локальные данные. Работа хранилища для `file://` зависит от браузера.
- Музыкальный блок и модель подготовлены; UI прикрепления/удаления композиции и музыкальный каталог отсутствуют. Без композиции показывается честное пустое состояние.
- Серверный ID, синхронизация, применение правил приватности на сервере, настоящая авторизация/сеансы требуют backend.
- Видеофайлы исходной демонстрации отсутствовали. `assets/aqua-demo.webm` — собственный синтетический 8-секундный ролик с тихим тоном и явной подписью. Это не видеосообщение реального человека. Выбор качества появляется только при предоставленных вариантах источника.
- Проверено в cloud Chromium. Safari, физические iOS/Android, системная клавиатура и реальные safe areas требуют проверки на устройствах. Fullscreen, clipboard и громкость зависят от браузера/платформы.

## Где редактировать

- `profile-media.js`, `profile-media.css` — профиль, аватар, карточки канала/музыки, ID, фото/видеопросмотрщик.
- `settings.js`, `settings.css` — категории, форма аккаунта, сохранение, выбор приватности и исключения.
- `pages.js` — существующий стек внутренних страниц, история, сохранение DOM и прокрутки.
- `app.js` — базовые данные, чаты, сообщения, маршрутизация корневых вкладок.
- `motion.js`, `chat-transition.js/css`, `dock.js/css`, `chrome.js/css` — общий механизм движения, чат и нижняя панель.
- `style.css`, `mobile.css`, `typography.css`, `polish.css` — базовые стили/темы/типографика. `locale.js` — локализация старых экранов; новые компоненты используют `AquaSettings.t`.
- `assets/` — локальные шрифты, изображения, лицензии, Anime.js 4.5.0 и деморолик.
- `checks/` — браузерные сценарии этого этапа. Они изменяют тестовые локальные данные: запускайте только в отдельном тестовом профиле/источнике с русским языком. Это выражения для browser eval, а не Node-тесты.
