# Aqua — HTML-прототип, round 10

Продолжение round 9 из предыдущего ZIP. Основной проект и GitHub не изменялись.

## Как открыть

Распакуйте ZIP целиком. Для быстрого просмотра на телефоне откройте **aqua-standalone.html** в браузере с включённым JavaScript: ресурсы встроены, интернет не нужен. Ограничения Android content:// зависят от файлового менеджера; при блокировке JavaScript используйте другой браузер или HTTP-сервер.

Редактируемая версия: **index.html** с соседними CSS, JS и папкой assets. Рекомендуемый запуск из папки прототипа:

```sh
python3 -m http.server 4175
```

Откройте http://localhost:4175. После правок пересоберите копию для телефона:

```sh
python3 build-standalone.py
```

## Полноценные страницы

- Нажмите имя или аватар в заголовке переписки: профиль собеседника, медиа, закрепления, уведомления, отправка профиля.
- Контакты → «Добавить»: поиск в локальном демокаталоге по имени, @username или телефону, результат и добавление. Примеры: @marina / +79990000001, @artem / +79990000002. Незнакомый запрос показывает пустой результат.
- Медиа: фото, видео, файлы, аудио; отдельный просмотр и возврат к исходному сообщению.
- Закрепления: несколько сообщений, открепление и переход в переписку. Закрепите сообщение через его контекстное меню. В начале закреплений нет; прежний фиктивный текст заменён честным пустым состоянием.
- «+» в списке чатов → новый канал или группа: название и описание → аватар → доступ/участники → проверка → создание. Кнопки «Назад» и история браузера сохраняют черновик между шагами.
- Пересылка, поиск в переписке, выбор контакта для отправки, участники, редактирование своего профиля и учётных данных также имеют страницы.
- Настройки → Настройки чатов → Тема: светлая или тёмная. Выбор хранится в памяти вкладки.

Кнопка «Назад», Escape и история браузера возвращают предыдущий экран. Страницы сохраняют DOM, поля и позиции прокрутки. В разделах без навигационной панели она скрывается. Реакции, меню команд, вложения и подтверждение удаления остаются компактными.

## Демонстрационные ограничения

Данные и новые каналы/контакты живут в памяти до перезагрузки. Нет backend, звонков, реального поиска пользователей, отправки приглашений и серверного изменения пароля. Роль пользователя для закреплений — администратор в этой демонстрации. Статусы доставки не выдумываются.

Медиа берутся из существующих сообщений: для видео доступен демонстрационный кадр, для файла и аудио — карточка без бинарного содержимого. Загруженный аватар хранится локально в памяти; принимаются PNG/JPEG/WebP до 3 МБ.
