## Исправления и первопричины

1. **Мигание чата.** AquaMotion после завершения каждой дорожки отменял native effect. Это возвращало элемент к начальному inline-состоянию scrub(0) до завершения всей сцены. Диагностический тест воспроизвёл возврат opacity с 1 на 0. Добавлен opt-in retain только для дорожек чата: законченная дорожка сохраняет явно заданные конечные свойства до scrub/clean владельца сцены. Отменённая дорожка не записывает устаревший финал. Концепция shared elements и обратного перехода сохранена.
2. **Онлайн-точка.** Клон аватара наследовал overflow:hidden и параметры псевдоэлемента из строки, отличавшиеся от шапки. Во время перехода одна временная точка следует геометрии аватара между измеренными полными границами точки в списке и шапке. Псевдоэлемент клона выключен; исходники скрыты вместе с аватарами. После завершения остаётся штатный индикатор. Цвет и форма не изменены.
3. **Лупа.** Её 180мс fade заканчивался раньше 280мс перемещения капсулы, затем эффект сбрасывался к видимому состоянию до общего callback скрытия. Теперь целевые opacity/transform заданы как underlying state до старта эффекта, выход длится 320мс с отдельной кривой presence, появление — 300мс. Сохранены поколения для быстрых переключений и контекстная доступность поиска; во время выхода недоступная кнопка inert и aria-hidden.
4. **Вкладки.** Новый порядок: Чаты → Контакты → Настройки → Профиль. Изменены navItems и tabOrder; направление переходов по-прежнему вычисляется из реальных DOM-индексов.
5. **Точечная оптимизация.** Сохранение терминальных свойств не читает layout и не вызывает commitStyles для скрытых мобильных кнопок. Общий исполнитель, Anime.js, жесты и структура проекта сохранены.
