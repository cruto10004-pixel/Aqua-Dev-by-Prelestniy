# Aqua: дизайн и проверка

Основа — предоставленный архив прототипа и левая колонка Beta 1 на референсах. Сохранены логотип, Manrope, существующие API, веб-модули и настройки. Новая базовая палитра: фон `#131a2b`, поверхность `#202b43`, приподнятая поверхность `#293550`, акцент `#b1c5ff`, входящее сообщение `#25324b`, исходящее `#3a4977`. Старые пользовательские акцентные палитры остаются доступными.

Веб-токены и компоненты: `frontend/css/aqua.css`. Шрифт из прототипа содержит кириллицу, лицензия рядом. Строка чата 76 px, аватар 48 px, основной текст 14 px; кнопки не масштабируются целиком. Нижняя панель 52 px, поиск 52×52 с радиусом 18 px. На десктопе боковая колонка 360 px.

`frontend/js/ui/search-morph.js` измеряет кнопку и родительский контейнер, использует Web Animations с завершением по `finished`. При закрытии фиксируются текущие width/left в px, right исключается; после завершения временные стили удаляются. Повторные нажатия во время перехода игнорируются. Изменение ширины во время перехода безопасно отменяет его; открытая строка адаптируется CSS. Уменьшение анимации учитывается через prefers-reduced-motion.

После изменений JS обязателен `node tools/build_bundle.js`: HTML загружает bundle, не исходные ES-модули.

Проверка поиска в авторизованном Preview на списке чатов:

```sh
coderabbit-agent-browser eval "$(cat tests/search_morph.browser.js)"
```

Реальные локальные проверки используют отдельный `AQUA_DATA_DIR`, данные проекта не заменяются демонстрационными.
